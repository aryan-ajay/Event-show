# Event Listing Website 🎉

An interactive web application that allows users to register, log in, list events, and add comments on specific events.

## 🚀 Features
- 🔐 **User Authentication** – Secure login and signup functionality.
- 📅 **Event Listing** – Users can view all listed events.
- 📝 **Comment System** – Users can add comments to specific events.
- 🏠 **Home Page** – A well-designed homepage showcasing featured events.
- 📱 **Responsive Design** – Fully optimized for all devices.
